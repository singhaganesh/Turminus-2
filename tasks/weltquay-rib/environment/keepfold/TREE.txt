weltquay mill
===============

Layout rows live in /app/ribcards/LAYOUT.txt.
Each row is a name, a bit index, and a width.
The first bit of a field is the high end of that bit's octet.

pour reads /app/quaybag/night.bin and writes /app/blotbay/rows.json.

Pipeline work: kiln take, layout row load, pour writer, and a baked pull that pour reads. Layout rows feed that bake.
