Change card lines:

  BUDGET <integer>
  ORIGIN <token>
  FILE <path>
  LINES <integers>
  END

Coverage count for a name is how many (FILE, line) pairs appear both on the change card and on that name's mesh sheet. Rank pool by that count, highest first. Equal counts: the lexicographically smaller identifier sits earlier.

names is the longest prefix of pool whose durations from /app/durcards/ticks.txt sum to at most BUDGET. spent_ms is that sum.

slate.json is one object: keys pool, names, spent_ms in that order, no extra whitespace inside arrays besides JSON commas.

slate.bin concatenates: four bytes SLT1, uint16be pool count, then that many records of uint16be length plus UTF-8 identifier, then uint16be names count and the same record shape, then uint32be spent_ms.
