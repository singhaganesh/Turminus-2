Event descriptions use NAME then FIELD lines. FIELD kinds are u8 and u16.

Ledger lines are name|relpath|field:kind,... with kinds u8 and u16. Ledger field tokens follow the FIELD declaration sequence in the description.

Each decoder file begins with KDEC1, then NAME <name>, then one field kind line per FIELD declared in the description, in that declaration sequence.

Decode JSON uses kind decoded or unknown, plus name. When decoded, fields is an integer map keyed by those FIELD names.

Frame bytes are a 4-byte big-endian name length, the name, then packed big-endian field payloads.

Decode fields object keys are the FIELD names from that description (for example latch, force, amp, bit, thick, mm, q, n, w).
