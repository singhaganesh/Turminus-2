URN1 records use three fields, one per line after the URN1 banner:

id <token>
day YYYY-MM-DD
n <integer>

counts.json is one object. Key order is days then covers.

days maps calendar day strings to integer totals. Each urn contributes its n to the day written on that urn.

covers is the identifier of the urn last folded by steep.

Shipped samples: id core on 2024-03-11 with n 3; id quiet on 2024-03-10 with n 2.
Valid extra id token z9 may use day 1999-01-01.
