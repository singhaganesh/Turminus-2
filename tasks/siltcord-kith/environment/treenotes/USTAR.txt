ustar member header is 512 bytes. name occupies bytes 0-99. size octal occupies 124-135 (the slice end is 136). typeflag sits at 156: regular file uses ASCII 0 (the byte that Python writes as b"0"). Payload follows the header and is padded to 512.

walk_sig is hashlib.sha256 hex of regular-file names joined by newline in apply order (SHA-256). Length is 64. Alphabet is 0123456789abcdef.

A quarry of truncated bytes or a non-ustar stream such as not-an-archive returns nonzero. A ledger filled with xxxx is junk and quarry must rebuild members.idx from the sealed kith.

python3 -c import hashlib,sys; print(hashlib.sha256(sys.stdin.buffer.read()).hexdigest())
