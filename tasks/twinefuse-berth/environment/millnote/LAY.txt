rows.ndjson: one JSON object per dump row, dump order. Keys are id, hitch, tok (strings).
hitch.idx: one line per hitch token. Token, then a single space, then a comma-joined id list sorted by id bytes. Lines sorted by hitch bytes.
The hitch token on every row of a group is the least token among tokens in that group, compared as raw UTF-8 bytes. Pair files contribute tokens to the same group.
berth.ok: bytes o k newline after a successful sew.
