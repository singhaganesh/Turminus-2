Relay operations notes
========================

`/app/bin/crashrail compile` renders `/app/relaydesk/gen/routing_map.py` from
`/app/faultdata/roster.toml`. Tablegen walks the roster twice, so a full compile
pass takes about ten seconds on this bench.

The switchboard imports that module at route time. When import fails, every
signature answers as `platform-core` with `source: default` even though compile
exits zero.

Adjust the codemill tablegen sources so compile emits an importable map, then
rerun compile before routing checks.
