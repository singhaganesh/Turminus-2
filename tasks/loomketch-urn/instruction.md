The mill binary is `/app/bin/loomketch` and it must begin with bytes `\x7fELF`. Feed it bind: that walk loads journals from `/app/vatlogs`, then writes `/app/inkbay/bound.json` and `/app/inkbay/desk.tsv`. Source fixes under `/app` are required; the mill layout is `/app/deskcue/MAP.txt`. Static copies of the bound file or the desk sheet are not enough. The mill has to be a compiled ELF again. The verifier reruns `/app/bin/loomketch bind`.

A second bind on the same journal texts still lists every finding, yet issue numbers in `/app/inkbay/bound.json` permute so a given body is attached to a different issue. The pair of outputs must be byte-identical across two directory layouts of the same files, and across a rename of the worker journals that leaves the texts unchanged. Each desk row that cites an issue must keep that issue attached to the same body. Finding identity is the user frames with `__asan`, `__interceptor`, and `__hwasan` names omitted and with hex runs folded to a stable token; those identities must match the journals.

Each bound.json findings record carries issue, kind, frames, and body. Desk rows carry issue, kind, and body. Record fields, the desk header, GUARD text, and journal line shape are in `/app/deskcue/MAP.txt`. Success writes `/app/inkbay/GUARD` with the three letters ok. Empty or truncated journals must make bind exit non-zero; on those paths GUARD must not exist (false). A path outside `/app/vatlogs` must also fail with GUARD absent (false).
