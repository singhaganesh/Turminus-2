loomketch mill layout
=====================

ketchcli/main.rs dispatches bind.

Other crates sit beside ketchcli. Journals live in /app/vatlogs.
Fixture copies of those journals sit at /app/seed/vatlogs.
bind refreshes /app/inkbay/bound.json, /app/inkbay/desk.tsv, and /app/inkbay/GUARD.

bound.json uses object findings as a list of records
{ "issue": N, "kind": "<kind>", "frames": ["<sym>", ...], "body": "<text>" }
where issue is an integer that starts at 1. desk.tsv starts with header
issue	kind	body
then one tab-separated row per finding, using those same issue values.

Journal text is AddressSanitizer form: one ERROR: kind line followed by #N frame lines.
Template copy sits at /app/tplbay/bound.tpl.
walkcue/ holds an ops sidecar used when KETCH_ALPHA=1.

A bind root such as /tmp/loom_out sits outside /app/vatlogs and must fail.
