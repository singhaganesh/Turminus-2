Ops drive `/app/bin/draughtpin`. `sip` opens `/app/lib/libdraught.so` without a slot argument, reads one dump file, and rewrites `/app/inkvat/card.json`. `mark` opens the same shared object through a slot named in `/app/abifolio/RULES.txt`. `/app/bin/draughtpin` starts with the four-byte ELF header. Desk map: `/app/abifolio/WALK.txt`. Source fixes under `/app` are required. Correct mill pipeline modules named from that map. The verifier reruns `/app/bin/draughtpin sip` and `/app/bin/draughtpin mark`.

Programs that open the library without naming a slot still emit the pre-rework dump fold. `mark` of the current slot already emits the RULES fold. `mark` of the compatibility slot must keep the pre-rework fold. When `sip` still matches the pre-rework fold it exits non-zero and `/app/inkvat/SEAL` is absent.

Whitespace runs in a dump (TAB, LF, CR, SPACE) collapse to one SPACE; other bytes below 0x20 drop; trailing ASCII slash is stripped; ASCII letters lowercase. card.json carries slot, text, and kind. After `sip`, slot is the current slot from RULES.txt. text is the folded dump as UTF-8. Kind strings for sip and mark live in RULES.txt. Slot names live in RULES.txt. Success writes SEAL containing ok. A dump of length zero exits non-zero with SEAL absent. `mark` of a slot RULES.txt does not name exits non-zero with SEAL absent. On those faults SEAL existence is false. Hand-written output is not enough.
