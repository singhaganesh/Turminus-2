Investigators drive `/app/bin/finspool` on this image. That file must start with bytes `\x7fELF`. Source fixes under `/app` are required for the pipeline modules named from `/app/vatnote/ROUTE.txt`. Hand-written dest cards are not enough.

`knit` refreshes generated mill pieces. `sting THREAD OP DEST` takes the path that does not return. `DEST` must contain four UTF-8 lines and nothing more: `FIN1`, `thread=<THREAD>`, `op=<OP>`, `END`, each with one trailing newline. `look DEST` prints those four lines and exits 0 only when the file on disk is whole. Truncated, empty, or missing files make `look` exit non-zero.

`ease THREAD OP DEST` takes the path that returns. Either path must leave the same thread and op that were passed in. `DEST` belongs under `/app/bloturn`; anywhere else exits non-zero and must not leave a success file. Smash `DEST` and `sting` the same arguments: the dest must be whole again. An interrupted write leaves `DEST` as a whole four-line card or leaves no file — never a partial file. `/app/opsleaf/RIP` marks that interrupt. Leave a compiled ELF at `/app/bin/finspool`. The test pipeline reruns `/app/bin/finspool sting` then `/app/bin/finspool look` on `/app/bloturn/final.rec`.
