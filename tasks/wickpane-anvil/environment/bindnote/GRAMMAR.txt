Take lines are space-separated fields:

  KIND ADDR MODULE FUNC

KIND is `.` for a named frame or `i` for a fold line.
MODULE may include a `+` tail. Pane `mod` is the MODULE text before `+`.
FUNC is the frame name.

A pane is `mod!fn` for each kept frame, joined by `|` in file order.

Fold: a KIND `i` line does not emit its own chunk; it belongs to the next named frame.
Omit: MODULE whose `mod` is `[vdso]` or `[vsyscall]` does not emit.
Reject: KIND `BAD` aborts `bin` with a non-zero status and must not replace a prior success bins.json. `/app/shardops/live/poison.stk` is such a take.

JSON objects map take basename (strip `.stk`) to pane text. Keys are those basenames only (`p3`, `q9`, `n7`, `s7` among them).

`/app/loomwell/pair.sha` is sha-256 / sha256 hex (64 lowercase chars) of the shared n7/s7 pane string, one line. It matches `sha256sum` of that pane text.

Two `bin` runs with the same live tree write identical `bins.json` bytes.
