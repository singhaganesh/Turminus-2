Heap card (text):

HPK1
NODE <id> <class> <bytes>
EDGE <from> <to> KIND <field>
ROOT <id> <rootKind>
SITE <id>
END

KIND is STRONG or WEAK.
A retaining chain uses STRONG edges only.
PATH is hop labels of a shortest retaining chain from a ROOT to the SITE.
When several STRONG hops reach SITE, PATH uses the class.field of the STRONG hop into SITE.

Ledger lines, SITE class ascending:

SITE <class>
BYTES <n>
PATH <rootKind>><Class>.<field>>...><Class>.<field>
