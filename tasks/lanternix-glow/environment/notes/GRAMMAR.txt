Recipe cards under /app/cardwell use:
  id: <CODE>
  slots: name, name
Slot names are opaque strings copied from the card as written. Readout keys
must match those names exactly. Sample names on this image are identifiers;
a mill still has to round-trip whatever names a card declares.

Sample cards on this image: LAN_WARM_01 slots lux,hold_s; LAN_BEAM_44 slots az_deg,el_deg;
LAN_FLASH_9C slots candela,dwell_s; LAN_GLOW_2B slots hue,period_s.

Sample lamps: /app/lamps/flash9c.lamp, /app/lamps/held.lamp, /app/lamps/warm.lamp,
/app/lamps/beam.lamp, /app/lamps/alien.lamp.
Lamp files under /app/lamps use:
  CODE <CODE>
  name=value

Readout JSON: {"code": <str id or void>, "slots": <dict of name to str value>}
Gap probes may write a temporary ghost.card under /app/cardwell.
Offline Go builds use GOPROXY=off and GOFLAGS=-mod=mod.
