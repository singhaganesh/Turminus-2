Overnight contract desk is `/app/bin/seamwick`. Source fixes under `/app` are required for the pipeline directories named from `/app/opsleaf/MAP.txt`. A static or hand-written blot is not enough. Drive `nudge` and `flood` so `/app/blot/last.json` is produced by the mill. The verifier reruns `/app/bin/seamwick nudge`, `/app/bin/seamwick flood`, and `/app/bin/seamwick sheet` as listed in `/app/opsleaf/VERBS.txt`. Keys for `/app/blot/last.json` are written in `/app/opsleaf/SHEET.txt`. Notes sit under `/app/opsleaf`.

`nudge` still returns 0 after `/app/corpus` tightened a published type. `flood` on that same tree records a finding on a path that `nudge` left out of assayed. Opening that path alone still reports the finding. `/app/blot/last.json` holds assayed, findings, and code. Each findings object has unit, kind, and note. unit is the path under `/app/corpus`. kind is `arity` for a call whose argument count differs from the published type. note is the call name. code is a decimal integer written as text. If `nudge` and `flood` would not share findings, or if assayed skipped a path `flood` would flag, `nudge` must return nonzero. Dirty trees leave findings as a nonempty array. On a `nudge` for a single tightened published type, assayed must not include a path that does not name that type and that `flood` would not flag. A unit that names that type only as a same-package identifier belongs in assayed. A later tightened type following a previous `flood` still has to share findings with `flood`.

`sheet` prints the current blot. assayed, findings, and code are the named keys.
