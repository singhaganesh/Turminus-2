`/app/bin/pcfold render` maps `/app/benchframes/bench.samples` through `/app/symmill/fold/runtime.symmap` into `/app/symmill/fold/profile.json`. The symmap begins with PCFOLD1, carries mode and buildid lines, then sym rows. Profile frames report symbol and offset per pc. Fresh `ring_dispatch` and `legacy_worker` PCs still resolve inside older neighbour symbols. A buildid that does not match the live runtime must make `/app/bin/pcfold check` exit non-zero. Sym spans must follow the linked runtime layout, not a uniform object-merge width.

Correct fold pipeline modules named in `/app/symmill/ops/pipeline.map`; source fixes under `/app` are required. Manual or hand-written symmap and profile files are insufficient. Field semantics are in `/app/symmill/contract.md`. The verifier reruns `/opt/verifier/bin/pcfold-grade render` on held-out sample lines.
