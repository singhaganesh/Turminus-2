Sanitiser triage on this image is `/app/bin/kindspill`. `brew` loads every sheet under `/app/sanitdesc`, refreshes `/app/spillbay/kinds.ord` plus `/app/rankbin/ranks.bin`, then writes `/app/docket/filed.bin`. `peek` prints the docket as JSON. Correct the pipeline modules named in `/app/notes/LAYOUT.txt`; source fixes under `/app` are required. Static copies of the list or docket are not enough. After source work, `/app/bin/kindspill` must be a native ELF binary again. The verifier reruns `/app/bin/kindspill brew` and `/app/bin/kindspill peek`.

After a kind is added to a sheet, older findings land at the wrong severity while the newly added kind looks right. Each kind's filed severity must equal the RANK on its sheet. A newly added kind must be filed at its declared RANK. `brew` must exit non-zero when any filed severity would not match its sheet. Sheets use a `KIND` line then a `RANK` line. `peek` prints `{"findings":[{"token":"<id>","severity":N},...]}` with string `token` and integer `severity` from 0 to 9. Tokens that differ only by letter case or by hyphen versus underscore name the same kind. `kinds.ord` lists one id per line. `ranks.bin` and `filed.bin` are concatenations of records: a 2-byte big-endian name length, that many UTF-8 bytes, then one rank byte.
