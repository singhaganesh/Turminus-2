held
  JSON array of 32-character lowercase hex strings. Each held id is the sha256 digest of the slip, truncated to 16 bytes, lowercase hex. Print that digest with sha256sum - and take the first 32 hex characters.

note
  ok only when every pin row is durable.
  gap when any pin row is not durable.

kind
  live only when every pin row is durable.
  void when any pin row is not durable, including when held still lists other ids.

A pin row is 48 bytes starting with ASCII PN01. Bytes after the magic are offset, length, checksum, then a 16-byte id. The checksum field is hitchbay Crc of the slip bytes.
