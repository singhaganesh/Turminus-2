capset.tbl line grammar

REEL
MARK <integer>
SLOT <token>
STAMP <8 lowercase hex>
CALL <name> <id> <class>

Poured rows use class token live.
SLOT on a poured blob is the leading hex prefix of that blob's STAMP (four digits).
A SLOT that does not match that prefix must not load.

spin prints one JSON object with string keys loaded, status, and call.
loaded is table: plus the STAMP value when the poured blob is used.
loaded is builtin: plus a stock token when compiled-in names are used.
status is replayed when the active name set covers the spool call.
A spool file is a single token: the call name.
open.reel is sys_openat2. held.reel is sys_held_pair. splice.reel is sys_loom_splice.
spin accepts any spool path whose token appears on /app/tapewell/desc/calls.lst.
