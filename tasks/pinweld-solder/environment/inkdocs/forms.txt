points.reg
  One hook name per line, ASCII sorted, no blanks.

runtime.lst
  Same names as points.reg, same order.

scan.log
  One line per processed unit: seen <absolute-path>

poke NAME
  On success print fired:<NAME> and exit 0.
  If NAME is absent from runtime.lst, exit non-zero and print nothing.
  The stock salvage-path mark is salvage_drain.

census
  Exit 0 only when points.reg holds the union of WELD_HOOK names visible
  under every recipe file in /app/recipath. Exit non-zero if any such name
  is missing. Names only visible under recipes that do not ship must stay out.
