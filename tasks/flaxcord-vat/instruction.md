Ops drive `/app/bin/flaxcord`. `spin` reads a capture directory under `/app/spoolbay` and writes a compact file under `/app/cordwell`. `unreel` prints one line per sample as `frame>frame COUNT n`. `differ` compares two compact files position by position and writes `/app/cordwell/differ.txt`. Line grammar sits in `/app/vatnotes/forms.txt`. Desk map: `/app/vatnotes/ROUTE.txt`. `/app/bin/flaxcord` starts with the four-byte ELF header.

Two process runs of `spin /app/spoolbay/day /app/cordwell/live.pfl` currently `unreel` to matching names and totals, yet a byte compare of the two compact files is noisy and `differ` reports every position changed. `/app/spoolbay/dusk` is the same workload with chunks packed under other filenames; unreels match `day`, but `differ` on the two compact files is still noisy. Source fixes under `/app` are required; correct the C pipeline modules named in `/app/vatnotes/ROUTE.txt`. After that, two process spins of `day` must emit byte-identical `/app/cordwell/live.pfl`; `spin /app/spoolbay/dusk /app/cordwell/alt.pfl` must make `differ /app/cordwell/live.pfl /app/cordwell/alt.pfl` write exactly `quiet`; `unreel` of `live.pfl` must print the same joined frame paths and totals as `unreel` of `alt.pfl`, one line per sample, lines ordered by the joined path. A capture that omits a chunk trailer must make `spin` exit non-zero; `/app/cordwell/spin.ok` is false and the file is absent. Success writes `/app/cordwell/spin.ok`. Hand-written compact files are not enough. The verifier reruns `/app/bin/flaxcord spin`, `/app/bin/flaxcord unreel`, and `/app/bin/flaxcord differ`.
