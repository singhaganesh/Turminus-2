Kiln CLI lives at /app/bin/kilncli.

Subcommands:
  impress PATH  apply every *.sql under /app/inkstack/migrations/ onto PATH
  spill         fill /app/vats/worker.vat for assay
  assay         read /app/vats/worker.vat, print schema_version, write /app/vats/assay.ok on success

The Makefile at /app/Makefile ships /app/bin/kilncli from the kilncli module.

Sources that implement those subcommands:
  /app/hopsrc/imprint
  /app/claybin
  /app/scorepit

Ledger intent: /app/inkstack/intent.toml
Workspace vat path used by local experiments: /app/hearth/focus.txt
