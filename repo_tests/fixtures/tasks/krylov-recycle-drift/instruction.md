The ladder driver under /app advances a family index across segments. The current emission drifts on mirrored scenarios during the transition. In failing runs, paired rows disagree on status bits and on the sixteen-character lane stamp, and the summary can remain diverged even with mostly repaired rows.

The summary records rows_total, reload_status, generation_span, and probe_digest. Healthy-run expectations for those row fields, the reload_status string when the ladder finishes coherent, the rule that defines generation_span from tilt_code values across rows, and the probe_digest reduction steps are specified in the module-level doc comment directly above the Rust entry point in /app/w0/v79/src/main.rs, including the literal aligned label for reload_status on a fully coherent emission. Keep mirrored pairs pairwise consistent (north with north_echo, ridge with ridge_echo, plain with plain_echo), and derive summary status from the same finalized row values that are written to output.
